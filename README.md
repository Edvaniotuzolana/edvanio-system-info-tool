# Edvanio System Info Tool

## 📌 Descrição

Edvanio System Info Tool é uma ferramenta desenvolvida em Shell Script para recolher informações básicas do sistema Linux através do terminal.

O projeto permite visualizar dados importantes do computador de forma rápida e organizada.

## 🚀 Funcionalidades

- Nome e versão do sistema
- Utilizador atual
- Data e hora
- Informação da memória RAM
- Espaço disponível no disco
- Informação do processador
- Endereço IP da máquina
- Diretório atual

## 🛠️ Tecnologias utilizadas

- Shell Script (Bash)
- Linux Terminal
- Comandos Unix/Linux

## 📂 Instalação

Clone o repositório:

git clone https://github.com/SEU-USUARIO/edvanio-system-info-tool.git

Entre na pasta:

cd edvanio-system-info-tool

Dê permissão:

chmod +x system-info.sh

Execute:

./system-info.sh
